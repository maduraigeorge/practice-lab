Upload a database or schema file

      
Click or drop a file here
.sql dump · .tar / .tar.gz / .tgz · .zip · .csv · .sqlite / .db

      
Works with dumps from PostgreSQL (pg_dump --no-owner --inserts, or default COPY format) and MySQL / phpMyAdmin exports. They are cleaned up automatically and loaded into the browser sandbox; anything SQLite can't run is skipped and listed. Archives may contain several .sql / .csv files. Your file never leaves your computer.
      PostgreSQL custom/tar-format backups (-Fc, -Ft) can't be read – export plain SQL instead.
