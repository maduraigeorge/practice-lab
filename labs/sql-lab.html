phpMyAdmin is just a web page for MySQL – connect to the MySQL/MariaDB server behind it (usually host localhost, port 3306, the same user and password). Your password goes only to the bridge on this computer, is held in memory and is never saved. Tip: use a read-only database user for real data.

        How do I get a file from my server?
        
    
          
  • phpMyAdmin: pick the database → Export → format SQL → Go.

  • pgAdmin: right-click the database → Backup… (any format) – or run pg_dump --no-owner mydb > dump.sql.

PostgreSQL and MySQL dumps are cleaned up for the browser's SQLite engine; anything it can't run is skipped and listed. Your file never leaves your computer. For real live connections run the local bridge (bridge/start.bat) – a Connect tab then appears here.
